## 原生 IP、住宅 IP、双 ISP，这三个词到底在说什么

这三样东西经常被混着讲，但风控系统看它们的方式完全不同，弄错了会白花钱。

**原生 IP** 指的是这段 IP 真的由当地运营商或机房在当地分配，不是从别处广播过来的。它的作用是让平台相信“你人在那儿”，流媒体解锁靠的就是这个。

**住宅 IP** 更进一步。IP 数据库（IPinfo、ipapi、AbuseIPDB 这类）会把这个地址标记为家宽（Residential），而不是数据中心（Data Center）。平台看到数据中心 IP，默认你是服务器、是代理、是批量操作；看到住宅 IP，默认你是坐在家里的普通用户。TikTok 运营、跨境电商多店铺最怕的就是这一层被识别出来。

**双 ISP** 是丽萨主机的说法，意思是这段 IP 在两个独立的 IP 数据库里都能查到 ISP 属性，等于上了双保险。但这里有个必须说清楚的事实：**数据库标记是 ISP，不代表这段 IP 的底层不是机房**。实测英国双 ISP 那台机器时就能看到，两个 type 值确实都是 isp，可 IP 仍然由 Cogentco 机房段分配。相比之下，美国 9929 那款在 IPinfo、ipregistry、ipapi、AbuseIPDB 四个库里一致显示为 Residential，属性更硬。同样是“住宅 IP”，成色是有差别的，这一点很少有人在评测里讲。
